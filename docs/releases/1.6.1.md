# waves 1.6.1

- Match p5.waves defaults for non-finite inputs and options.
- Capture sampler options at creation; create a new sampler to apply changed options.
- Preserve all 35 formulas and the gentle, harsh, closing and ghost groups.
- Include generated HTML API reference, source, license and all 14 examples.
- Add waves.pdex for direct installation alongside waves.zip and waves.txt.

Validation: 55 numerical cases and 720 p5-derived regression checks; packaged
library installed in a clean Processing 4.5.6 sketchbook on Ubuntu 24.04,
all 14 examples compiled, and basic_demo, ghost_delay and color_field ran
for five frames under a virtual display.

The API retains Processing float precision and integer seeds. macOS and
Windows runtime tests are not part of this release's automated checks.

Install waves.zip into your sketchbook's libraries directory so that
waves/library/waves.jar exists, then restart Processing.

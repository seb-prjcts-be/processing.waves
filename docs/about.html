About

Pass a number in, get a number back. processing.waves provides 35 wave formulas for motion, colour, shape or pattern in a Processing sketch.

The Java port

processing.waves is the Java port of p5.waves for Processing 4. It keeps the wave names and indices. Java results are checked against the JavaScript reference within the tolerances below.

Use the waves in Processing's draw() loop, passing time from your sketch. The library has no native dependencies.

Matching Java and JavaScript

The port needs the hash, pseudo-random generator and formulas to agree across Java and JavaScript. These are the implementation choices behind that comparison:

  • FNV-1a 32-bit hash, returning the unsigned uint32 as a Java long so the subsequent float math matches JS's unsigned-Number semantics.

  • mulberry32 PRNG, ported bit-for-bit. A given seed produces the same sequence on both sides of the language border.

  • double-precision internal math, narrowed to float only at the public API boundary, preserving double precision for intermediate calculations and returning Processing float values.

Numerical validation

The numerical validator runs the JavaScript reference through Node and compares the Java output for 55 cases. A second suite runs 720 regression checks, covering every wave, group membership, non-finite input and sampler options.

Wild mode allows a larger tolerance because noise modulation amplifies differences between float and double. These are numerical comparisons, rather than a guarantee that all renderings will look identical.

35 shapes, four pools

Every wave has a character, and the library groups them so you can lean into the one you want:

  • Gentle: calm and bounded. Sines, cosines and modulos, plus the sharp-but-periodic shapes like square and pulse; hard edges, dependable rhythm.

  • Harsh: breaks rhythm. Tangent-spiked or noise-driven, but also the ones that simply refuse to stay calm; bald patch accelerates without bound, half sine keeps changing its stride.

  • Closing: the set whose period divides 2π·n cleanly. A shape drawn over a full cycle joins back to itself without a seam, which is what you want when you sweep a wave around a circle.

  • Ghost: six closing waves hand-picked to stay clean when a wave is plotted against a delayed copy of itself; that pairing draws the wave's phase portrait as a closed loop.

Choose a wave by name, let a seed choose from a group, blend two waves with mix, or enable shift to move between formulas at the interval you set.

Java API

  • Fluent builder instead of object literal. Java doesn't have JS-style options objects, so WaveOpts uses chained setters: new WaveOpts().wave("triangle").amplitude(80).

  • No runtime string evaluator. JS p5.waves carries each formula as display metadata plus a precompiled function. Java uses hand-written lambdas, one per wave. Neither implementation evaluates formula strings at runtime, so there is no surface-level difference.

  • Pure math, no browser glue. No DOM, no canvas wrappers, no event handlers. The library plugs into Processing's draw loop like any other math utility.
